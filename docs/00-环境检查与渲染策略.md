## 二、低负载渲染策略（已落地）

### 1. 渲染参数

| 参数 | 调整前（Remotion 默认） | 调整后 | 说明 |
|---|---|---|---|
| 并发 `--concurrency` | 8（半核数） | **测试 1 / 正式 2** | 峰值 CPU 从接近满载降到可边渲染边办公 |
| 缩放 `--scale` | 1.0 | **测试 0.5**（540×960） | 像素量降到 1/4，自检够用 |
| 帧率 | 30 fps | **30 fps 保持不变** | 交付要求，不降 |
| 中间帧格式 | PNG（无损） | **JPEG 85** | 少一次无损压缩/解码 |
| 编码 | 默认 medium | **veryfast / crf 26** | 编码时间明显缩短，观感无差 |
| 浏览器 | 下载 Headless Shell | **复用本机 Edge** | 省 150MB 下载与额外磁盘 |

配置位置：`remotion.config.ts`（全局生效）+ `scripts/render-low.mjs`（参数兜底，防止误用高负载参数）。

### 2. 画面实现层面的省算力约定（后续镜头全部遵守）

- **地图一律“预烘焙”**：卫星/地形瓦片先由脚本离线拼成整张大图，Remotion 里只做 `scale / translate` 的相机运动，**不运行 MapLibre/Cesium/WebGL**。既避免无 GPU 环境下软件光栅化烧 CPU，也保证每一帧完全确定、不会闪烁。
- **禁用高开销 CSS/SVG 效果**：不用大半径 `filter: blur()`、`backdrop-filter`、多层 `box-shadow`、SVG `feGaussianBlur`；柔和阴影、雾气、纸纹一律预先画进 PNG/渐变图。
- **人物动画用“分层 SVG + 关节角度插值”**，不用逐帧位图，也不用 AI 逐镜头生成（既保证形象一致，也不产生视频解码开销）。
- **文字与字幕用 DOM 文本**，不做逐字模糊动画。
- **分段渲染**：长镜头按 3–5 秒一段渲染再拼接，避免长时间占满 CPU；任何时候都可以中断续跑。

## 三、待办与已知限制

- Chrome Headless Shell 不走下载路径，**所有渲染命令必须经过 `render-low.mjs` 或带 `--concurrency` 参数**，否则会退回默认 8 并发。
- 卫星影像为 Esri World Imagery，画面角标需标注来源；仅用于现代地形参考，**不得当作元末地貌依据**。
- 本机无 Blender，三维地形飞行为“卫星/地形大图 + 2.5D 相机运动”，非真实三维模型。
