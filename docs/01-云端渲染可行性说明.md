## 二、为什么不能直接上云（三条路，各自卡点）

### 路线 A：GitHub Actions（最省事，免费额度够用）

- **卡点**：需要「能向 GitHub 写代码」。本机 HTTPS 写通道被代理拦截（502），SSH 通道虽通但没有密钥，gh CLI 也装不上。
- **需要你做的（约 2 分钟，任选其一）**：
  1. 在 GitHub 建一个空仓库 → 本机生成 SSH key → 把公钥加到该仓库的 Deploy key（勾选 write）→ 我这边加 remote 即可 push；
  2. 或给本机配一个 GitHub Personal Access Token，并允许 https 访问 github.com。
- **成本**：公开仓库 0 元不限时长；私有仓库每月 2000 分钟免费，本项目一次成片约 5–10 分钟。
- **工作流已写好**：`.github/workflows/render.yml`，支持手动选 Composition / 帧段 / 缩放，产物以 artifact 下载。已内置 `fonts-noto-cjk` 安装，避免 Linux 上中文变方框。
- **注意**：云 runner 是 4 核，`--concurrency=4` 是合理值；本机不需要跑任何渲染进程。

### 路线 B：Remotion Lambda（最专业，按次付费）

- **卡点**：需要 AWS 账号 + AK/SK + 一个 S3 bucket，首次部署会创建 Lambda 与 IAM 角色。本机无任何 AWS 凭证，且这属于**付费服务**，我不能擅自开通。
- **成本**：按渲染次数与时长计费，单条 90 秒 1080p 视频通常几分钱到几毛钱级别（不含 S3 流量）。
- **需要你做的**：提供一组有 Lambda/S3 权限的 AWS 凭证（建议用子账号 + 最小权限），我再执行部署与渲染。

### 路线 C：阿里云 ECS / 函数计算（你有阿里云账号，但没有对应 AK）

- **卡点**：现有 Key 是百炼 DashScope 的推理 Key，**不能**用于开通 ECS 或函数计算；且开实例属于付费操作。
- **成本**：按量付费 ECS（4 核 8G）约每小时几毛到一两块，渲染完即释放。
- **需要你做的**：提供有 ECS 权限的 AccessKey，或你自己开一台机器把工程拷上去跑一条命令。

> 三条路都需要一次人工授权，这是政策与账号问题，不是技术问题。我不能擅自使用你的账号或产生费用。

## 三、本地渲染的降负载方案（已实现并实测）

即使最终走本地，也已经把占用压到很低：

| 措施 | 做法 | 效果 |
|---|---|---|
| 优先级降级 | `--priority=idle`（默认开启）→ PowerShell 设 `PriorityClass=Idle`，Edge 子进程继承 | **前台程序永远优先抢 CPU**，渲染相当于"见缝插针" |
| 并发限制 | 测试 1 / 正式 2（Remotion 默认 8） | 峰值从接近满载降到约 1–2 个核 |
| 分辨率分级 | 自检 `--scale=0.5`（540×960），只有最终成片才 1.0 | 像素量降到 1/4，自检几分钟完成 |
| 中间帧压缩 | JPEG 85 而非 PNG | 少一次无损压缩/解码 |
| 编码器 | x264 `veryfast` + crf 26 | 编码时间缩短，观感几乎无差 |
| 画面预烘焙 | 地图瓦片离线拼成大图，运行时只做相机变换；不跑 MapLibre/Cesium/WebGL | 避免无 GPU 时软件光栅化烧 CPU |
| 禁用高开销效果 | 不用大半径 `blur()`、`backdrop-filter`、SVG 高斯模糊 | 每帧光栅化成本稳定且低 |
| 分段渲染 | 按镜头拆分 Composition，一次只渲一段 | 可随时中断，不必长时间占用 |

**实测**：以空闲优先级渲染 10 帧（540×960）成功，日志确认 `已把渲染进程降到 Idle 优先级（Edge 子进程继承）`，输出 `out/priority-test.mp4`。

## 四、建议的分工

| 环节 | 建议位置 | 原因 |
|---|---|---|
| 素材烘焙（瓦片拼接、贴图） | 本地即可 | 纯 IO + 轻计算，一次几秒 |
| 分镜自检（单帧 / 3 秒片段） | **本地**，半分辨率、空闲优先级 | 需要肉眼反复看，云端来回传反而慢 |
| 最终 1080×1920 成片 | **云端**（路线 A/B/C 任一） | 时长最长、负载最高，正是要挪走的部分 |
| 成片检查与修改 | 本地播放 | 只需解码，占用极低 |
