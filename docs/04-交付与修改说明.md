## 〇、v1 → v2 的核心改动（按审核意见）

- **移除原有人物动画**：v1 的分层 SVG 纸偶角色（兵卒/同知/仓官）因动作偏生硬，已整体删除（`HuangZishou.tsx`、`Scenes.tsx` 两个模块已移除）。
- **改为以地图为主视觉基底**：全部镜头以卫星影像 / 历史地形图作底，通过**文字标注（Callout）+ 战斗/冲突图标**来讲叙事。
- **战斗/冲突图标体系**：刀枪交火（`swords`）、火光（`flame`）、海寇船（`ship`）、进攻/退敌方向箭头（`Approach`）、防御盾（`shield`）、粮袋（`grain`）、县印（`seal`）、城门（`gate`）、牌坊祠（`shrine`）、告身文书（`scroll`）、海浪（`wave`）、旗（`banner`）、村落（`village`）、山（`mountain`）、星标（`star`）、冠（`crown`）。
- **转场更自然**：相邻镜头用**交叉溶解**（相邻 Sequence 重叠 12 帧，容器淡入淡出），不再是硬切。
- 史实口径与 v1 一致，继续沿用 docs/03 的校正结论。

## 五、渲染方式

本地低负载：
```
node scripts/render-low.mjs HuangZishou out/HuangZishou.mp4 --full --priority=idle
node scripts/render-low.mjs HuangZishou out/clip.mp4 --frames=780-820 --priority=idle
```
云端：push `main` 自动触发；或 Actions 页 `workflow_dispatch`（composition=HuangZishou, scale=1）。

## 六、已知限制 / 待用户确认

1. **观感需你过目**：当前对话模型不支持读图；地图聚焦点取影像中心（未做地理配准），历史边界为示意。建议本地预览确认；如需把镜头精确对准旺埇村/水口镇，给经纬度我再校准 `focusX/focusY` 与标注坐标。
2. **战斗为图标化示意**：交火/火光/船队均为图标化表达，非写实战争场面。
3. **史料来源未获原书影像**：B/C 级引文来自网络转引（见 docs/03 第四节），正式发布前建议补核方志原书卷次。
4. **旁白与画面**：旁白 84.1s、成片 86.2s，末段片尾约 2s 无旁白，属正常。
